# Portable research experience — locked direction

Near-black observatory, soft ice-blue and muted lavender, thin coordinates and slow geometry. No neon, scores, simulated medical scans or invented research findings. Persian reading direction; English research names isolated left-to-right. System fonts keep the file fully offline. Large questions and generous negative space take precedence over decoration.

Four parts: (1) question → observation metaphor → theory and four disciplines → Masiha → path map; (2) fourteen guided chapters with worked examples and explicit arguments; (3) claim register, source library, five study comparisons, challenges, proposed study and English reviewer brief; (4) six-step presentation and a complete research notebook export. Completion describes the prototype's four sections, not validation of the theory.

Each chapter has four focused steps: observation and meaning; optional visual interaction; possible mechanisms and alternatives; evidence, limits and proposed test. Simple/scientific mode reveals detail without hiding caveats. Navigation, range controls, dialogs and exports remain keyboard accessible. Reduced motion and the explicit pause control suppress motion. All demonstrations identify synthetic quantities.

Evidence is curated, non-exhaustive and claim-specific. Contradictory replication is visible. No trained model, participant data, diagnosis, institutional endorsement or established novelty. Data integration should replace a separate content module, preserving provenance, measurement definitions and validation status.

Deliver one HTML file with inline styles and a bundled React island; no server, installation, fonts, API or internet required. External research and contact links intentionally require connectivity. Hash routes preserve back navigation and work with file URLs. Downloads carry their own content. User-entered text is escaped, never interpreted as markup.
