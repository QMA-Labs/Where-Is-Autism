# اتیسم کجاست؟

**هندسهٔ یک ذهن توزیع‌شده — ایدهٔ پژوهشی و تجربهٔ تعاملی مسیحا نایری**

![جلد اختصاصی پروژه](docs/assets/cover.png)

اگر همان فرد در دو موقعیت، یا با دو روش پاسخ‌دادن، عملکرد متفاوتی نشان دهد، دقیقاً چه چیزی تغییر کرده است؟ چه بخشی به فرد مربوط است و چه بخشی به شرایط مشاهده و ابزار بیان؟

این پرسش، آغاز پروژه است. برنامه موضوع‌هایی مثل توجه، تجربهٔ حسی، بیان عاطفه، ارتباط، صفات خانوادگی و محیط را در مسیری ۱۴ فصلی کنار هم قرار می‌دهد. هر مشاهده به تفسیر، توضیح رقیب و آزمون احتمالی خودش وصل می‌شود.

## منظور ایده چیست؟

اطلاعات یک پاسخ را همراه با زمینه و روش درخواست آن بررسی کنیم. «توزیع‌شده» یعنی اطلاعات مرتبط می‌تواند در موقعیت‌ها و اندازه‌گیری‌های مختلف قرار داشته باشد؛ نه اینکه اتیسم میان اعضای خانواده پخش شده یا والدین مقصر باشند. «هندسه» زبان پیشنهادی برای رابطه‌هاست؛ تصویرها، دادهٔ واقعی یا کشف زیستی نیستند.

**آزمون پیشنهادی اول:** آیا متغیرهای ازپیش‌تعریف‌شدهٔ محیط و روش پاسخ، پیش‌بینی یک پیامد مشخص را در افراد کنارگذاشته‌شده برای ارزیابی، نسبت به مدل پایه بهتر می‌کنند؟

وضعیت فعلی، چارچوب مفهومی آزموده‌نشده و نمونهٔ نرم‌افزاری قابل‌اجراست. دادهٔ شرکت‌کننده، مدل آموزش‌دیده، نتیجهٔ تجربی تازه یا ابزار تشخیص معتبر در پروژه وجود ندارد. منبع مرتبط با یک جزء، کل چارچوب را اثبات نمی‌کند.

## دو مسیر ورود

**نسخهٔ فارسی:** تجربهٔ تعاملی، ۱۴ فصل، حالت ساده و علمی، نمایش‌های مفهومی، راهنمای محلی، شواهد و جمع‌بندی ارائه.

**نسخهٔ پژوهشی انگلیسی:** معرفی، ایده‌ها و فرضیه‌ها، شواهد و مطالعهٔ پیشنهادی؛ همراه با دریافت پروندهٔ کامل و درخواست کوتاه پژوهشی.

## اجرا از سورس

به Node.js نسخهٔ ۲۲٫۱۸ یا جدیدتر و npm نیاز است:

</div>

```sh
git clone https://github.com/QMA-Labs/Where-Is-Autism.git
cd Where-Is-Autism
npm ci
npm run build:portable
```

<div dir="rtl">

سپس فایل فارسی `outputs/where-is-autism-complete/index.html` یا نسخهٔ انگلیسی `outputs/where-is-autism-research-edition/index.html` را در مرورگر باز کن. خواندن این نسخه‌ها به سرور و اینترنت نیاز ندارد؛ لینک مقاله‌ها و تماس به اینترنت نیاز دارد.
